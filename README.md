# קניות לבית

PWA פשוט בעברית לניהול קניות לבית:

- מסמנים מה חסר.
- רואים רשימת "לקנות עכשיו".
- מוסיפים מוצרים חדשים.
- מדביקים קבלה כדי שהסוכן ילמד מה קניתם לפעם הבאה.
- מתקינים באייפון דרך Safari -> Share -> Add to Home Screen.

## פיתוח מקומי

```bash
python3 dev-server.py
```

ואז לפתוח:

```text
http://127.0.0.1:4178/
```
